AuditKIT

AuditKIT is a Python library for evaluating any AI model on any dataset with one API. Evaluation is usually fragmented: academic benchmarks, LLM-as-a-judge, red-teaming and performance profiling each come with their own tools. AuditKIT puts them behind a single call, so results can be compared across all of them. I built it at Lexsi Labs.

  • One pipeline: dataset, adapter, model, metrics, result. A single evaluate() call runs it, and one model can be run across many datasets at once.
  • Many kinds of evaluation: benchmarks (exact match, F1, BLEU, ROUGE), LLM-as-a-judge, code and format checks, RAG groundedness, hallucination, toxicity and bias, pairwise preference, agent and tool use, security, and performance.
  • Red-teaming: built-in adversarial probes (prompt injection, jailbreaks, encoding tricks, over-refusal) with detectors for injection success and system-prompt leaks.
  • Any model: ten backends, including OpenAI, Anthropic, Hugging Face, vLLM, LiteLLM and Groq, a deployed agent over HTTP, or any plain Python function.
  • Reproducible: the core needs only the standard library, and every run gets a stable hash so results can be cached and compared.

Projects

Circuit discovery for the IOI task on Llama 3.2 1B
Mechanistic interpretability · Code
I wrote the whole circuit-discovery pipeline by hand, using layer-by-layer and token-by-token activation patching on Indirect Object Identification, with no TransformerLens or other interpretability library. From 80 components (MLP layers and attention heads), logit-difference thresholds picked out a candidate circuit of 7 MLP layers and 10 attention heads. Removing it cut the task score from 5.39 to 0.50. Against matched random baselines, the chosen components were far more important than random ones, but the results exposed a gap between necessity and sufficiency. The layer-level results held across three seeds, on a laptop GPU (Apple MPS) at about 2.5 GB of memory.
Architectural determinants of KV-cache compressibility
Efficient inference
How far can a transformer's KV cache be compressed without retraining? I applied SVD-based optimal low-rank approximations to the Key and Value projection matrices of eight language models to find the safe limit. Models with QK-norm and grouped-query attention kept only 24–35% of the hidden-state width with no accuracy loss. I also used the singular-value structure to see which directions matter for decisions, and checked that compressed caches still work when one agent hands its context to another.
Chain-of-thought faithfulness in financial LLMs
Lexsi Labs · ongoing
Do a model's written explanations reflect what it actually computes? I audited five models on financial decision-making by comparing their internal signals (linear probes, top-k logit-lens tracking, elicited probabilities) and an independent judge against the chain-of-thought they produced. I also built and evaluated two preference-optimization pipelines, IV-DPO and CF-DPO, to bring internal and verbal reasoning closer together. Chain-of-thought turned out to have weak causal influence on answers, and I diagnosed where the methods fall short (diluted preference pairs, limits of the metrics).
